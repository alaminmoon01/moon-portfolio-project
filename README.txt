MD ALAMIN PORTFOLIO — QUICK START

1. Extract this ZIP file.
2. Open the alamin_portfolio folder in VS Code.
3. Make sure the portrait image is at assets/alamin-portrait.jpg.
4. Open index.html in your browser, or use VS Code Live Server.
5. Edit index.html to replace the email, GitHub links, project descriptions, education details, and social links with your real information.

Files:
- index.html : page structure and content
- style.css  : responsive layout, colors, animation and mobile menu styling
- script.js  : mobile navigation, scroll reveal, active section and demo contact form
- assets/alamin-portrait.jpg : portrait used in the hero section

Note: The contact form opens the visitor's email app. To receive messages directly on a website, connect a backend or form service. Project links are sample GitHub links and should be replaced.
